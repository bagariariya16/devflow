# DevFlow

DevFlow is a cloud-native SaaS platform that enables developers and teams to manage application deployments using modern DevOps practices.

The platform provides:
- Project-based deployment management
- CI/CD pipeline automation
- Kubernetes-based application orchestration
- Cloud deployment on Azure

This project is built to demonstrate real-world full-stack and DevOps engineering practices, including microservices, Docker, Kubernetes, Helm, and CI/CD pipelines.

## Tech Stack
- Backend: Node.js, Express
- Frontend: React (planned)
- Containerization: Docker
- Orchestration: Kubernetes (AKS)
- Deployment: Helm
- CI/CD: GitHub Actions
- Cloud: Microsoft Azure
